.NET Framework – Definition
.NET Framework is a Windows-only software framework developed by Microsoft used to build desktop, web, and Windows applications, mainly for legacy systems.

.NET Core – Definition
.NET Core is a cross-platform, open-source, and high-performance framework developed by Microsoft to build modern web, API, cloud, and microservices-based applications.

| Feature    		 | **.NET Framework**       		| **.NET Core**                          |

| Platform    		| Windows only          		| Cross-platform (Windows, Linux, macOS) |
| Performance		 | Slower                 		  | Faster & lightweight                   |
| Deployment 		 | System-wide installation | Self-contained deployment              |
| Open Source 		| ❌ No                 		    | ✅ Yes                                  |
| Cloud Ready 		| Limited          	        | Fully cloud & microservices friendly   |
| CLI Support 		| Limited                 		 | Strong CLI (`dotnet` command)          |
| Updates     		| Slow                    		 | Frequent updates                       |
| Usage       		| Legacy & desktop apps    	| Modern web, API, cloud apps            |

*** .NET Core + .NET Framework are now merged into just .NET (from .NET 5 onwards)
